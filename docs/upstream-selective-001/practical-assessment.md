## Evidence notes

- Local baseline source: `desktop/src/renderer/src/store/chatStore.ts` commits `reasoning` immediately and patches `tool_progress` immediately; it also already batches `delta`. `MessageBubble.tsx` exports the un-memoized component. Candidate 9 changes these exact paths.
- Local baseline source: `desktop/src/main/index.ts` returns valid numeric saved bounds directly from `loadWindowState()` and saves `getBounds()` without checking display visibility. Candidate 10 adds sanitization and lifecycle rechecks.
- Local baseline source: `common/cloud_client.py::copy_send_file` uses `uuid.uuid4().hex` per call. Candidate 11 changes naming and copy reuse.
- Local baseline source: `channel/feishu/feishu_channel.py::start_client_with_retry` loops `range(2)`, retries only the first SSL failure, then exits on other exceptions. `upstream/master` includes `ea74daee` TLS correction after PR #3910; it still assigns `ssl_module.create_default_context` and `_create_unverified_context` and has no corresponding restore before thread exit.
- PR metadata: #3920 and #3919 were merged to upstream master; #3910 includes the TLS correction after the initial candidate commit. PR descriptions are author-provided reports, not independent runtime proof.
- Verification run: none. This was a read-only source assessment; no test command was run.
